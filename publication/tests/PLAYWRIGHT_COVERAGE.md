# Playwright coverage and intentional skips

The release suite uses Chromium, Firefox, WebKit and a JavaScript-disabled Chromium project. A
skip is permitted only when the same contract is proved once in the engine that can exercise it
reliably and the remaining engines still cover the shared page, navigation and accessibility
surface. Every `test.skip` call carries one of the identifiers below.

| ID            | Omitted executions                               | Reason and retained coverage                                                                                                                                                                                                                                                                     |
| ------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `PW-SKIP-001` | Theme tokens in Firefox and WebKit               | Exact custom-property values and automatic dark/light switching are asserted once in Chromium. Firefox and WebKit still load the same CSS and run the canonical static experience in the default theme. The light palette receives its own Axe route matrix under `PW-SKIP-003`.                 |
| `PW-SKIP-002` | 320/390/768/1440 matrix in Firefox and WebKit    | The complete overflow matrix is a deterministic layout assertion run once in Chromium to avoid multiplying identical static-CSS checks. Firefox and WebKit still render and navigate every shared test at their desktop device profiles. Real-device and zoom checks remain human release gates. |
| `PW-SKIP-003` | Light-theme Axe matrix in Firefox and WebKit     | The DOM is identical across themes; the full default-theme Axe route matrix runs in all three engines, while the CSS-only Daylight Proof colour change is re-audited once in Chromium. This does not claim manual assistive-technology coverage.                                                 |
| `PW-SKIP-004` | No-JavaScript test outside `chromium-no-js`      | `playwright.config.ts` excludes this file from the three ordinary projects and runs it once with JavaScript disabled. The built-artifact validator independently rejects executable client scripts on ordinary production pages. The in-test skip is a fail-safe if project routing is changed.  |
| `PW-SKIP-005` | Forced-colours emulation in Firefox and WebKit   | Playwright's automated forced-colours check is treated as a Chromium emulation contract. All engines retain semantic text and default-theme Axe coverage; manual Windows High Contrast review remains a release check rather than an automated cross-engine claim.                               |
| `PW-SKIP-006` | Static metadata assertions in Firefox and WebKit | The rendered JSON-LD and Open Graph records are server-generated bytes rather than browser-engine behaviour. Both metadata tests run once in Chromium; Firefox and WebKit continue to exercise the same generated routes through the shared navigation and accessibility suites.                 |

With the present project matrix, `PW-SKIP-001`, `PW-SKIP-002`, `PW-SKIP-003`, and
`PW-SKIP-005` each produce two skipped executions—one in Firefox and one in WebKit. The two tests
under `PW-SKIP-006` each produce two more, for 12 reported skips. `PW-SKIP-004` normally produces
none because project routing prevents the test from being collected elsewhere.

Safari/WebKit keyboard focus is not skipped. The test focuses the skip link directly because macOS
link tabbing follows the operating-system Full Keyboard Access preference, then exercises the same
activation and focus destination.
